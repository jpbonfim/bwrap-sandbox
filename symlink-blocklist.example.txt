# ==============================================================================
# Security-Hardened Sandbox: Workspace Symlink Blocklist (--resolve-symlinks)
# ==============================================================================
# Host paths that are never mounted when resolving workspace symlinks that point
# outside the project. A cloned repository may ship hostile links such as
# 'keys -> ~/.ssh', so keep this list conservative.
#
# Format: [rw:]<path>
#   <path>       # Blocked in every mode (--resolve-symlinks=ro and =rw)
#   rw:<path>    # Blocked only when mounting read-write (--resolve-symlinks=rw)
#
# Rules:
#   - Supports '~', '$HOME' and '$SANDBOX_DIR' (bwrap-sandbox installation directory).
#   - Paths must be absolute after expansion.
#   - A path also blocks every directory containing it (e.g. '~/.ssh' blocks links to '~' and '/').
#   - Entries that are themselves symlinks (e.g. dotfiles) also block their real location.
#   - Lines starting with '#' and empty lines are ignored.
#
# Always enforced regardless of this file: sockets, devices and FIFOs, targets
# containing the workspace itself, and targets containing a profile mount.
# ==============================================================================
